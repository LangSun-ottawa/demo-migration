This is a playground with four independent API experiments, not one large business form. Pick one card at a time; Angular sends the request and Django validates it centrally.

How to use this page

Start with the defaults

Every default value is valid. Submit one experiment, inspect its JSON result, then change one field to see which rule rejects or converts it.

  1. JSON bodyShows nested objects, arrays, optional fields, and type validation.
  2. Query stringShows URL parameter conversion and optional filters.
  3. File uploadShows filename, content type, and size validation without persistence.
  4. Redirect contractShows Angular reacting to structured 303 and 338 responses.
